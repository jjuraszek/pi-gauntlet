Load the body of roasting-the-spec, the chair persona body, and spec-finalization from Spec Council to before User Review Gate in headed assembly. Cases select their active stage; supplied file/status outcomes are data, not executed tools.

| Sample | Properties |
|---|---|
| member-file-only | Paired outputs on every task, targeted retry, structural quorum, harness invitation boundary |
| chair-file-only | Direct reads from explicit task paths without injection, complete output report, file usability and retry ladder |
| applier-dispatch | Snapshots, foreground fresh executor, full human/ticket/coverage context, inherited model/thinking |
| audit-rollback | Labels/counts, zero-cluster acceptance, reread first, restore before identical retry and abort |
| post-applier-reread | Nested untracked file enumeration, absolute worktree-rooted cleanup from outside cwd, before-set and parent-file preservation, gate continuity |

This no-tool text eval proves prescribed dispatch/check sequences only. It does not prove actual child file transport, filesystem rollback, SDK behavior, deletion safety, or gate rendering. Mechanical contract tests and runtime tests own those boundaries. Use eval/README.md for runs, cache rules and record schema.
