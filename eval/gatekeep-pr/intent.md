## Change

Show which PRs discovery kept before creating any worktree. The no-arg-discovery-note replay starts at argument resolution and stops at set admission. It checks which links and team wording the parent renders, how it summarizes an untrusted description, and whether it continues without a question. A grammar assertion cannot prove those choices. The no-arg-discovery-single replay checks the singular list and origin-bound handoff: a heading assertion alone cannot show whether the parent waits for a reply or enters batch routing. The over-cap and cc-multi replays render the messages at rejection: checking for the marker in the instructions cannot show whether it starts the stop message or displaces the earlier list. The under-cap replay checks that a team request without a membership match stays in the admitted set, and the zero replay checks that an empty search prints no list. The role-line-team replay isolates the report opening after refresh: a schema assertion cannot show whether the writer folds team requests into two sentences alongside authorship or a direct request. The role-line-requested replay checks that readable, nonmatching memberships preserve the existing role wording. Neither checks the typed list.
