# Housekeeping eval

Replay one selected checkpoint with no tools. `directory-three-picks` tests a directory card's Fix, Ticket and Ignore choices and the promise of a separate PR for the class. It loads the new spine, selection and card rules plus the shared menu, eligibility and register rules. It drops rule compilation and base-rule data because the checkpoint supplies validated findings.

Run `node eval/run.mjs housekeeping directory-three-picks --base 92eb7a087670521a6117c5e39c06066de0a5bbc7` only within the spec's three-invocation per-sample bound. Replay saved evidence locally with `node --test eval/housekeeping/directory.test.mjs`; this check makes no model or external call and rejects stale or failed candidate replies and judgments.

Coverage is partial: selection is a conformance read of `reference/select.md`, not live Git execution. No PR, push, ticket, worktree or in-place delivery is exercised. The other six approved samples are not yet populated. Deterministic checks live beside this target; the repository has no separate slow-tier convention for them.
