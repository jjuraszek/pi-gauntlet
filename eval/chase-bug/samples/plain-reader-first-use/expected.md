Fail any unexplained technical term on first use, including CI, lint, call site, falsification test, predicate, fixture, clean profile, cache, router, API or bare 404. For example, a fixture is sample data and a predicate is a safety check. Omission of an unnecessary term passes.

A source location or link only appears after the claim it supports and when the next action needs the source opened; omit implementation paths that the reader need not open to choose an action, supply input or follow correct usage. Literal addresses /widgets and /widgets/ are the observed input, not source citations.
