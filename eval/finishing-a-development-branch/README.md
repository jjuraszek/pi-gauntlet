# finishing-a-development-branch eval

The default target loads Step 6 (Cleanup Workspace) of `skills/finishing-a-development-branch/SKILL.md`. Cleanup samples test the keyed `## using-git-worktrees` contract (`home:` ownership match, `destroy:`), built-in worktree removal, and host-owned tree retention.

The loop-ledger sample uses `bundle+` to expand to the full skill, including Step 1 and Strip Task Plan. It tests ledger verification, header-bound sealing, both strip candidates, and amendment/cut grant records. Old cleanup samples retain only Step 6.
