# Spec-reviewer eval

Load the spec-reviewer persona body and SDD-local spec-reviewer template as a headed text assembly. Synthetic observations test exact task-anchor selection, spec authority, task/home-leg Rules, independent file review without commands, and unreadable-anchor failure mirrored in structured output.

The replay has no live tools. Samples request the next read and supply its observations; they do not simulate actual command execution. Verification owns model runs and saved results per `eval/README.md`.
