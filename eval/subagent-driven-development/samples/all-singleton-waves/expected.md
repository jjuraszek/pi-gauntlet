- singleton-dispatch: judged: Every plan task runs as an N=1 wave in a nested worktree using a one-entry tasks dispatch or one implementer-to-SR chain with a one-entry tasks step, never a lone plain implementer dispatch for a plan task. Supported runtime uses one initial chain per wave, not one chain per phase.
- task-spec-review: judged: Each task gets one initial SR reading its implemented tree via the chain's matching treePath on 7.4.0; the older-runtime alternative materializes its captured patch with git apply --index in a detached wave-base snapshot, not the unchanged parent or a deleted worker tree.
- integrated-gates: judged: For each of the three waves integrates the accepted patch with git apply --index, runs that wave's scoped command, then dispatches one initial CR over the integrated diff with BASE_SHA the recorded wave base and HEAD_SHA WORKTREE; no full suite is substituted.
- accepted-commit: judged: For each wave commits only after its required review accepts and then marks its task complete, preserving pending to in_progress to complete and recording the next wave base from the newly committed HEAD.
- retained-exemptions: judged: Keeps plain in-place repair and escalation dispatches as exceptions to plan-task isolation and keeps doc-only waves SR-only; does not force code review on doc-only work.
