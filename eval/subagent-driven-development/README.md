# Integrated wave execution evals

Exercise implementer-only initial waves, one integrated wave-reviewer after a green scoped gate (docs included), bounded direct report reads and repair-on-top. Source/spec/plan reads remain delegated. Deterministic Git recipe evidence lives in scripts/wave-review.test.mjs; these synthetic replays assert dispatch decisions, not live runtime execution.

The eleven replacement scenarios cover review count, bounded reads, isolated/in-place repair, red gates, empty deltas, repair-only rebuild, execution escalation, one convergence exception, funded stops, REJECT and answered BLOCKED state. Retained scenarios cover amendments, ordered source lookup, coordinated checkout-local Leg/Rules, package preflight, ledger recovery and verification handoff. delegated-amendment retains its original bytes.

Assembly uses target.json slices and candidate-only declarations. Parent verification runs the full target and commits genuine reports/results; historical result files are not current evidence after assembly changes.
