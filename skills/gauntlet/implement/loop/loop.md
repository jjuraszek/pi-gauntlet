# Loop implementation

Run this driver in the main session. Carry the absolute implementation worktree path as a value; run git with `git -C "<worktree>"` and commands as `(cd "<worktree>" && <command>)`. Carry the approved spec path and resolved plan directory. Keep the original prompt for verify. Never run reviewers inside implement. Read [commit-message.md](../../commit-message.md) for all commit wording. Resolve its absolute path from this installed file and resolve the ticket once at seed or authorized restore; pass `wording: <absolute path>` and `ticket: <reference or none>` to every worker. Use its fixed bookkeeping sentence for each parent event and its amendment source for amendments.

## Entry

1. Read project overrides below. Resolve `gauntlet_setting({ key: "loopEngine" })` and retain `maxIterationsPerRow` (default 4) and `escalateAfter` (default 3). Hold `escalateAfter` in driver memory for this run; never print it or write it to the ledger, and never re-resolve it inside the loop, including after amendment grant re-decodes. Stop on an unavailable settings tool. Select this run's seed value in step 4 and persist it only in the ledger, not in the spec or settings.
2. Resolve verification once using this ordered table. Print `verification command: <command> (<source>)`.

Capture the decoded grant, row dispositions, ordered leg membership, each leg's absolute checkout paths and combined spec/task Rules for dispatch and handoff; use home for zero or one leg. At an authorized fresh-session restore, resolve `gauntlet_setting({ key: "loopEngine" })` exactly once at this boundary and hold `escalateAfter` for the run; share that read with gauntlet-resume's `../../../gauntlet-resume/reference/restore-loop.md`. With an unavailable tool, stop before dispatch with `cannot resolve escalation threshold: settings tool unavailable (loopEngine.escalateAfter)`; never supply an in-loop default.

At seed and at an authorized restore, when the held membership has more than one leg, read `coordinated-legs.md` IN FULL now with read at its absolute path; stop on an unreadable reference naming its path, never reconstruct it. 3. Call `phase_tracker({ action: "skip", phase: "plan", reason: "loop engine" })`.
