# Unreachable returns

Key routing to the admitted return, not unchanged evidence. Keep an unanswered stop pending, including on resume. Treat a human retry, `rows +N`, an applied amendment answering the stop, or an applied cut as answering that return. Recover answered state on resume from the existing retry, raise-allowance and amendment decisions/commits after that admission; add no routing marker. Continue at the ordered table without re-firing its marker, even while the failed row's evidence is unchanged. Route a newly admitted failed return independently, even with identical evidence.

Inspect only the target's first result segment after the check name in its admitted evidence cell; split on unescaped semicolons and trim whitespace. Never inspect later result segments, other rows or a rejected return. Leave malformed markers on the ordinary failed-attempt path.

| First result segment | Action |
|---|---|
| Matches `^unreachable: unnamed action .+ - .+$` | Take the amendment surface's human batch before any write or dispatch, with or without amend permission. Ask whether to name the action in the spec or cut the row; wait for the answer. |
| Matches `^unreachable: .+ - .+$` otherwise | Take the amendment action below before another dispatch. |
| Otherwise | Return to the ordered table. |

Leave diagnosis to the child. At the start of the amendment, reuse the full procedure of [`human-stop.md`](human-stop.md) only if it is still available in the current context; otherwise read it in full now with `read` at its absolute path before acting. Stop on an unreadable file naming its path; never reconstruct it. Form one amend item outside the dispatch loop through [amendment-surface](../../amendment-surface.md), using the captured `<what>` and `<where>` from `unreachable: <what> - <where>` as evidence. Recommend disposition `deviates: unreachable in this checkout - <what>; proof at <where>` and an `## Out of scope` entry `<row text, first 60 chars> - unreachable in this checkout - <what>`. Reuse the surface's batch preparation, grant decoding and section 5 audit/ledger aftermath, including its redraw and repeated-evidence stops. Without amend permission take its human batch before any write or dispatch. Under amend permission apply the item: set the ledger row `cut` with the disposition as evidence in the surface's single amendment commit. Read [commit-message.md](../../commit-message.md) for its amendment source and ticket rule; append `amended | cut row <n> | <first item title>` in the ledger, and print `amended the spec: row <n> - unreachable in this checkout - <what>`. Preserve attempts, iterations, allowance and spent escalation. Refresh held state through the driver's Human stop amendment return and continue the ordered table in the same turn. Carry the cut on After the loop's `Deferred/deviates per spec:` line. For companions use the held mapping and coordinated amendment rules; the home spec/ledger own the cut.
