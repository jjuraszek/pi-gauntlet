# Human stop

Apply [menu-layout](../../menu-layout.md) only to a question with choices. Start the message with `gauntlet: question` at every human stop, including discard authorization for a dirty tree with no dispatch pending. Put it alone on the first output line, followed by a newline before the stop text, without a driver-state preamble, wrapper or code fence. These decisions are neither done nor stuck outcomes.

Leave implement active for implementation stops. For verify stops follow [After the loop](loop.md#after-the-loop), retaining verify active. Use one screen of plain words: `Stopped on row <n>` for row failures, or the concrete boundary/verification header. For row stops, quote the evidence cell and last decision line verbatim under `Problem:`; attribute any spec/code contradiction, failing assertion/output or missing capability to that evidence, without investigating it. For a stalled whole-diff review, use `Stopped on whole-diff review.` and quote the final review report's residual findings under `Problem:`. After `Problem:` print `Needs: <the input that unblocks delivery>` in everyday words. Name the specific missing input, not a list of actions. At every human stop, including allowance, missing-model, dirty-tree and exit-verification stops, list every `open` or `failed` row after the header as `row <n>: <attempts> of <effective allowance>`, then print `Preserve every row's attempts.` Compute each denominator from the ledger using [Before each dispatch](loop.md#before-each-dispatch); keep retry increments in `## Decisions`, never a new table column. Render repaired row cells after recovery, never unadmitted child results. With no open or failed rows, omit row lines but retain the preservation sentence. Name `escalated round spent` when applicable; omit round history and reasoning traces.

For stops not handled by [Unreachable returns](loop.md#unreachable-returns): At stalled and no-way-forward stops print no options or recommendation. Accept retry and `rows +N` only at row stops (allowance or missing-model) or seed exhaustion. Accept amendment requests at every stop. The dirty-tree stop with no dispatch pending keeps discard authorization only, never budget offers; the verify-step-1 verification-failure stop accepts only an amendment request. A budget increase never bypasses those gates.

For non-empty `status --porcelain` with no `pending:` tuple at [entry step 4](loop.md#entry) or on resume, render `Stopped: dirty tree with no dispatch pending`, list the dirty paths, and offer `discard` or Stop only, never budget offers. Before typed discard, make no tree or ledger writes, reset, clean or dispatch. On a typed `discard` run `git -C "<checkout>" reset --hard HEAD` and `git -C "<checkout>" clean -fd`, then resume the sequence the stop suspended: at fresh entry continue [Entry](loop.md#entry) step 4's ledger write and step 5; on a restore finish eligible migration and final allowance validation, then continue at [Before each dispatch](loop.md#before-each-dispatch) in implement or [After the loop](loop.md#after-the-loop) step 1 in verify. Never jump to the ordered table before a ledger is seeded and admitted. Any other reply preserves the tree and keeps the stop open.

| Human choice | Durable action |
|---|---|
| Raise allowance (`rows +N`) | Parse anchored `rows +<n>` with `<n>` matching `[1-9][0-9]*` and a token boundary (end, whitespace or `\|`); reject `rows +50x`. Trim the optional remainder and optional leading pipe into the words cell. Append `rows +<n> \| <words>` under `## Decisions`; bare `rows +50` writes `rows +50 \|`. Raise the shared header allowance by N for every row and leg. Commit both changes exactly once using the shared Allowance raise sentence, leaving iterations and all attempts unchanged; return to the ordered table. For malformed replies, including `rows +0`, `rows +x`, `rows -1` and `rows +50x`, print the accepted forms `retry <n> \| <hint>` and `rows +N` once. On the first and every later invalid reply, keep the same stop open with no writes, commit or dispatch; preserve allowance, decisions, iterations and all attempts. |
| Retry (`retry <n> \| <hint>`) | Parse the row number and hint from that reply. Append `row <n> retry \| <hint> \| allowed attempts <effective allowance + 1>`, commit with the shared Retry sentence, resume checks with that target/hint. Preserve the header allowance, every attempts cell and iterations; increment only that row's effective allowance by one. |
| Amend | Follow `/skill:gauntlet` amendment surface; cut only through an approved disposition amendment. Reconcile ledger and spec in one commit. |

Serialize the bare decision as `rows +50 |` with an empty words cell. Raising allowance resets neither window (empty-child or validation-miss); exclude allowance-raise commits from child-commit counting. Use [Before each dispatch](loop.md#before-each-dispatch)'s window rule for retry and admitted amendments.

Outside the dispatch loop, perform authorized amendment actions under the amendment surface's own reads. After the amendment commit, re-decode the grant and refresh the held row dispositions, membership, checkout paths and Rules from the updated spec before returning to the loop; apply this to funding and standing-grant amendments too. Leave the `**Amend-grant:**` header grammar unchanged.

For ledger amendments use its line-1 discriminant: no plan writer or plan_check. Approved deviates/deferred/elsewhere becomes `cut` with disposition evidence; requirement-preserving amendments leave rows unchanged; a re-bounded done row becomes `open` with `reopened by amendment`. Preserve attempts, iterations and allowance. Append `amended | <cut row n, or N item(s)> | <first item title>` and commit spec + ledger with the shared amendment source. Without amend permission, stop for amendments; with amend permission, auto-apply amends. Redraw always stops and deletes the ledger with the plan. Cut only through the amendment surface, including its standing-grant section 5.

Under amend permission take only a named authorized amend: print `took recommendation: amend for row <n>`, apply amendment-surface section 5 (including its audit), record the `amended` decision and commit using the shared amendment source, then return to the ordered table. Whitespace-normalize the row evidence cell and compare with evidence already auto-resolved on that row; repetition renders `Problem: evidence repeats row <n>`. Recover this evidence from amendment/ledger history; missing history never authorizes a repeated action. A cut leaves the stop; an unresolved row returns to rule 2 in its current window. Retry, `rows +N` and redraw wait for the human. Fix-first enters `/skill:shape-ticket`'s own gate, never an automatic separate repair. Hard boundaries never auto-take recommendations.
