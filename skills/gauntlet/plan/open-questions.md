## Ask the human

Start the message with `gauntlet: question` alone at column zero on the first physical line, followed by a newline, for every user-facing baseline-failure, dirty-source, or contract question, including a second verbatim `FAIL`. Never append a colon to the marker. Follow the [first-line rule](../menu-layout.md).

| Row form | Parent handling |
|---|---|
| `- Task N: ... fails on <sha>` | Name task, original command, SHA, exit and summary. Present three options, one per line: `fix-first` - run `/skill:shape-ticket` for the base failure (its own gate applies), then report the plan paused and end the turn; `narrow <filter>` - name a concrete filter or path when evidence supports one, otherwise request it; `amend` - use [the amendment rules](../amendment-surface.md) section 5. Follow with `Recommendation: <option>[ <filter>] - <reason>`. Resolve permission before waiting: read the approved spec header grant through ../amendment-surface.md's structural predicate and Value decoding. Under amend permission print `took recommendation: <option>` and take the named recommendation: `narrow <filter>` re-dispatches per `plan.md` `## Author the plan` step 3 with the exact filter in Findings (for example `narrow hook-config` sends `Task N Tests: narrow to hook-config`); `amend` runs section 5; `fix-first` enters `/skill:shape-ticket`, whose own gate is the only remaining stop. `none` or `narrow` without a concrete filter waits. With no amend permission (budget-only, `none`, or absent), retain the menu and wait for the human. Never infer consent for a redraw or restoration. After fix-first lands, bring the advanced base into the worktree through `../worktrees.md`'s existing advanced-base procedure (rebase, or merge for a shared branch), re-dispatch per `plan.md` `## Author the plan` step 3 with `Findings: rerun baseline`, then `plan.md` `## Author the plan` step 5; after a session break use `/skill:gauntlet-resume`'s baseline continuation. For narrow, re-dispatch with a Findings row `Task N Tests: narrow to `<text>``; for amend, use section 5. Both run Baseline's rerun rule before `plan.md` `## Author the plan` step 5. |
| `- Baseline: worktree dirty`, `- Baseline: in-flight source edits`, `dirtied tracked source`, `moved HEAD` | Restore-and-rerun, not the menu: name paths and cause. Clear the parent's own wave/amendment source work through its own commit step; list doc-only work under `In-flight:` before re-dispatch. Take every other path, including every test-dirtied path, to the human to commit, discard, or move; never clean automatically. Once restored, re-dispatch per `plan.md` `## Author the plan` step 3 with `Findings: rerun baseline`, then `plan.md` `## Author the plan` step 5. Bullet `artifacts:` need no action. |
| Other substantive rows (contract questions) | Present the rows, wait for answers, re-dispatch per `plan.md` `## Author the plan` step 3 with the answers as the `Findings:` block, then `plan.md` `## Author the plan` step 5. |

On a pause retain phase `plan` as `in_progress` and its substep; no stamp or `plan_tracker` init.

For a second identical FAIL, present the FAIL lines, verbatim, as an exhausted finding does.
